Multiplication Table Generator
A simple Java program that takes a number from the user and prints its multiplication table from 1 to 10.

📌 Description
The MultiplicationTableGenerator program demonstrates basic Java concepts such as:

Taking user input using Scanner

Storing values in variables

Using a for loop

Performing multiplication

Printing formatted output to the console

🛠️ Technologies Used
Java

Java Scanner

For Loop

git clone <your-repository-url>

🧠 How It Works
A Scanner object is created to read input from the user.

The user enters an integer.

A for loop runs from 1 through 10.

The program multiplies the entered number by the current loop value.

Each multiplication result is printed to the console.

The main calculation is:

int result = number * i;
